Stack y arquitectura

Una arquitectura por capas en vez de instalar varias librerías completas que resuelvan lo mismo.

1
Fundación visual
shadcn/ui (sobre Radix) + Tailwind CSS v4 + TypeScript. Botones, inputs, diálogos, menús, tarjetas, badges, calendario. El código es tuyo y se adapta.
2
Capa de datos
TanStack Table: orden, filtros, paginación, selección y columnas. Sin diseño impuesto; se viste con .nx-table.
3
Capa analítica
Tremor o Recharts para gráficos y métricas, con los tokens de color de la marca. Añádela cuando un módulo la necesite.
4
Identidad
Variables CSS y tokens (@nexus/brand) con variantes propias. Aquí viven el oro, el negro, los radios y el movimiento.

Que una librería sea gratuita no significa que sus complementos lo sean: MUI X y AG Grid Enterprise reservan funciones de pago. Revisa la licencia de cada catálogo antes de usarlo en un producto comercial.
