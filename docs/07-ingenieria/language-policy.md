# Política de idiomas

## Propósito y alcance

Evitar la mezcla de idiomas en documentación, desarrollo y comunicación técnica.

| Elemento | Idioma |
| --- | --- |
| docs/ y README principal | Español |
| AGENTS.md y CONTRIBUTING.md | Inglés |
| Código, identificadores, comentarios técnicos y pruebas nuevas | Inglés |
| Ramas, commits y pull requests | Inglés |
| Interfaz | Español por defecto, preparada para internacionalización |

Los nombres oficiales y términos técnicos se conservan. Esta política no traduce código, contratos, pruebas funcionales, decisiones aceptadas ni mensajes históricos. Preparar internacionalización es una regla para futuros cambios de producto; esta limpieza no implementa ni declara existente una infraestructura nueva de i18n.
