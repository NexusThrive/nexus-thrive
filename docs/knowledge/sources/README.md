# Fichas de fuentes

Una ficha por fuente relevante, con el mismo `id` que el catálogo. Sirve para que
una persona entienda la fuente sin abrir el JSON.

## Plantilla

```markdown
# SRC-… — <título>

- **Tipo:** official_docs | project_docs | code | incident | research | internal | user_story
- **Procedencia:** …
- **Ubicación:** ruta local o URL
- **Añadida:** YYYY-MM-DD
- **Última verificación:** YYYY-MM-DD
- **Estado:** active | stale | unavailable | rejected
- **Confianza:** high | medium | low
- **Módulo:** …
- **Etiquetas:** …

## Qué aporta

…

## Qué no cubre

…

## Riesgos

Contenido no confiable, versión desactualizada, licencia, etc.

## Sincronización

Adaptadores usados y último resultado.
```

## Regla

El catálogo JSON es la fuente de verdad; esta ficha es documentación para humanos.
Si divergen, gana el catálogo y la ficha se corrige.

No hay fichas todavía.
