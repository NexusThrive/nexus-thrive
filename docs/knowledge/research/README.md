# Investigación

Fichas de investigación con fuentes verificables. Escribe aquí el
`research-engineer`; el `knowledge-engineer` mantiene procedencia y vigencia.

## Plantilla

```markdown
# <pregunta>

- **Fecha:** YYYY-MM-DD
- **Estado:** abierta | resuelta | insuficiente evidencia
- **Contexto:** por qué se investiga
- **Restricciones:** versión, licencia, coste, datos

## Fuentes

| Fuente | Tipo | URL / ubicación | Fecha | Confianza |
|---|---|---|---|---|
| … | oficial | … | … | alta |

## Hallazgos

…

## Incertidumbre

Qué no se pudo verificar y por qué.

## Recomendación

…

## Qué haría cambiar la decisión

…
```

## Reglas

- Cada afirmación relevante se apoya en una fuente citada.
- Se distingue documentación oficial, documentación del proyecto y opinión.
- Se indica la versión exacta de la herramienta investigada.
- Si no hay evidencia suficiente, se declara; no se rellena con suposiciones.
- No se incluyen enlaces inventados ni fechas estimadas presentadas como reales.
