# Tipografía

| Familia | Uso | Clase |
| --- | --- | --- |
| **Montserrat** 600–700 | Títulos, cifras grandes, la marca | `font-display` |
| **Inter** 400–600 | Interfaz, formularios, tablas | `font-sans` (por defecto) |
| **JetBrains Mono** 400–500 | Códigos, IDs, atajos, contadores | `font-mono` |

Las cifras siempre con `tabular-nums` para que no bailen al cambiar. Las mayúsculas con
tracking amplio son solo para la marca y los antetítulos (`Eyebrow`).
